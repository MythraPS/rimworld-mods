# RimWorld mods

- **IranianRugs** — Iranian Rugs (for VFE - Art): Vanilla Furniture Expanded - Art's small, large and grand rugs redrawn as Iranian-style hand-knotted rugs, 17 designs picked at random, the field tinted by the rug's material. `Source/make_rugs2.py` generates the textures, `Source/make_preview.py` the Workshop preview.
